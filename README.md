# 🎯 Projeto: Raio-X da Juventude

O **Raio-X da Juventude** é uma iniciativa focada em diagnosticar as condições de vida, socioeconômicas e educacionais de jovens por meio da coleta e análise de dados. O projeto processa informações para gerar insights acionáveis, visualizados em um dashboard interativo, com o objetivo de embasar políticas e ações sociais voltadas ao ensino e ao bem-estar.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Análise de Dados:** Pandas, NumPy
* **Visualização:** Matplotlib, Seaborn, Plotly, Chart.js
* **Ambiente:** Google Colab
* **Front-end:** HTML5, CSS3, JavaScript
* **Hospedagem:** GitHub Pages
